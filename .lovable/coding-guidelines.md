# Coding Guidelines

- Runtime: Node.js (React) / PHP (Laravel)
- Formatter: Prettier (JS/TS), Pint (PHP)
- Naming rules: PascalCase for Enums/Database, camelCase for TS variables, snake_case or camelCase per Laravel standard.
- Error handling rules: Errors must be explicitly logged, Universal Response Envelope format.
- Restrictions: See `.lovable/strictly-avoid.md`.
